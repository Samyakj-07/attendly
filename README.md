# 🛡️ IPU Attendance OS
> **"Know your attendance. Before it becomes a problem."**  
> *The sovereign attendance management & academic intelligence native mobile application for students of Guru Gobind Singh Indraprastha University (GGSIPU).*

---

## 💎 Features at a Glance

1. **🏛️ IPU Detain Risk Radar & Strict 75% Condonation Shield**:
   - Live buffer calculations (+3 classes safe to bunk or −4 classes needed).
   - Real-time Ordinance 11 compliance radar.
2. **🚀 "CAN I SKIP TODAY?" Hero Decision Engine**:
   - Analyzes every class scheduled today.
   - Categorizes into 🔴 **DO NOT MISS**, 🟡 **ATTEND IF POSSIBLE**, and 🟢 **SAFEST TO MISS**.
   - Outputs a tactical plan with overall attendance impact.
3. **📊 Exact Class Simulator ("What-If")**:
   - Simulates missing 1, 2, 3, 4, 5+ classes with exact percentage drop ladder and marks the 75% threshold crossing point.
4. **🛣️ Step-by-Step Recovery Roadmaps**:
   - Step 1 (Class 1 → 72.6%), Step 2 (Class 2 → 73.4%), ..., Step 5 (Class 5 → 75.4% 🎉 Safe Zone Reached).
5. **📅 Mon–Sat Weekly Timetable & Daily Class Generator**:
   - Automatic generation of today's schedule.
   - 1-Tap `Present`, `Absent`, `Cancelled` (never penalized), and `OD / Condonation` marking.
   - 1-Tap **Mass Bunk / Faculty Leave Protocol** for the entire day.
6. **🎯 IPU 5/5 Internal Assessment Marks Predictor**:
   - Live prediction of your internal marks based on university slabs ($\ge 90\% = 5$, $85-89\% = 4$, etc.).
7. **📑 Official IPU Attendance PDF Statement**:
   - Generates a formatted PDF report with college header, enrollment details, and subject ratios ready to share or print.
8. **💬 Ask IPU Academic Assistant**:
   - Natural language assistant answering questions using your actual attendance ledger.

## 📱 How to Run on Your Mobile Phone

### Step 1: Start the Expo Development Server
Run the following command in your terminal:
```bash
npm start
```
or
```bash
npx expo start
```

### Step 2: Open on Physical Phone (iOS & Android)
1. Install the **Expo Go** app from the App Store (iOS) or Google Play Store (Android).
2. Scan the QR code displayed in the terminal with your phone's camera (iOS) or the Expo Go app (Android).
3. The app will launch with native performance and haptics!

### Step 3: Run on iOS Simulator (Mac)
Press `i` in the terminal to launch the iOS Simulator.

### Step 4: Run in Web Browser
Press `w` in the terminal to open the web version.
