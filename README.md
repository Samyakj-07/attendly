# attendly
> **"Stay ahead of attendance."**  
> *The premium attendance intelligence application for college students.*

---

## 💎 Features at a Glance

1. **📊 Attendance Target & Buffer Shield**:
   - Live buffer calculations (+3 classes of buffer or −4 classes needed to get back on track).
   - Real-time university criteria compliance radar.
2. **🚀 "Can I skip today?" Decision Engine**:
   - Analyzes every class scheduled today.
   - Categorizes into 🔴 **DO NOT MISS**, 🟡 **ATTEND IF POSSIBLE**, and 🟢 **SAFEST TO MISS**.
   - Outputs an instant prediction with overall attendance impact.
3. **📈 Exact Class Simulator ("What-If")**:
   - Simulates missing or attending 1, 2, 3, 4, 5+ classes with exact percentage drop ladder and marks the target threshold crossing point.
4. **🛣️ Step-by-Step Recovery Roadmaps**:
   - Class-by-class recovery ladder with exact milestone calculations to reach the safe zone.
5. **📅 Weekly Schedule & Calendar Attendance**:
   - Interactive monthly calendar with color-coded daily status dots.
   - 1-Tap `Present`, `Absent`, `Cancelled` (never penalized), and `OD / Official Duty` marking.
   - 1-Tap **Mark All Present** for the day.
6. **🎯 Internal Assessment Marks Predictor**:
   - Live projection of your internal attendance marks based on curriculum slabs.
7. **📑 Official Attendance Statement (PDF)**:
   - Generates a formatted PDF report with college header, enrollment details, and subject ratios ready to share or print.
8. **💬 Ask Attendly**:
   - Natural language assistant answering questions using your actual attendance ledger.

## 📱 How to Run on Your Mobile Phone

### Step 1: Start the Expo Development Server
Run the following command in your terminal:
```bash
npm start
```
or
```bash
npx expo start
```

### Step 2: Open on Physical Phone (iOS & Android)
1. Install the **Expo Go** app from the App Store (iOS) or Google Play Store (Android).
2. Scan the QR code displayed in the terminal with your phone's camera (iOS) or the Expo Go app (Android).
3. The app will launch with native performance and haptics!
